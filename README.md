# TripTailor Pro

Crea una aplicación web llamada NextTrip para recomendar viajes personalizados según el presupuesto. Incluye un onboarding interactivo con preguntas (estilo de viaje, con quién viajas, ritmo, intereses) y un slider interactivo de presupuesto desde 100€ hasta 10000€. Al enviar, muestra 3 opciones de viaje con desglose de costes (transporte, estancia, actividades) y tarjetas visuales cuidando mucho la estética y el diseño moderno. Añade un selector de ciudad de origen. Añade un botón para exportar o guardar el itinerario. Haz que la barra de presupuesto cambie de color según el rango.
